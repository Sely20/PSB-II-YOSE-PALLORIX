# PSB-II-YOSE-PALLORIX
Pengembangan Perangkat Portabel untuk Skrining Anemia Non-Invasif Berbasis Pengolahan Citra Telapak Tangan dengan Sistem Pencahayaan Terkontrol
YOSE Pallorix merupakan perangkat pencitraan portabel untuk mendukung skrining awal anemia melalui analisis karakteristik warna telapak tangan (palmar pallor). 
Parameter utama berupa karakteristik warna telapak tangan yang diekstraksi dari area ROI pada citra, dengan parameter evaluasi: lux, konsistensi RGB/L*a*b*, ketepatan ROI, repeatability, dan hasil klasifikasi.
Hasil perangkat merupakan skrining awal, bukan pengganti pemeriksaan Hb laboratorium.
